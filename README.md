 🎬 Movie Recommendation System

 📌 Overview
A recommendation system built using collaborative filtering on the MovieLens dataset.  
The system suggests movies to users based on viewing patterns and user similarity.  

🔧 Tech Stack
- Python (pandas, NumPy, scikit-learn)
- Colab
- Dataset: MovieLens

🚀 Steps
1. Data Preprocessing
2. Exploratory Data Analysis (EDA)
3. Model Building (Collaborative Filtering)
4. Evaluation & Results

📂 Files
- `movie_recommendation.ipynb` → main notebook
- `README.md` → project documentation
